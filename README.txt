VANTA — Creative Digital Studio
================================

Thank you for choosing VANTA!

VANTA is a modern, responsive HTML/CSS website template designed
for creative studios, agencies, freelancers, startups, and
small businesses.

--------------------------------
WHAT'S INCLUDED
--------------------------------

• index.html
• style.css

--------------------------------
HOW TO USE
--------------------------------

1. Open the VANTA folder.
2. Open index.html in your web browser.
3. Edit the text in index.html to add your own content.
4. Save your changes and refresh the browser.

No frameworks or complicated setup are required.

--------------------------------
CUSTOMIZING YOUR WEBSITE
--------------------------------

You can easily change:

• Brand name
To change the brand name:
Use Ctrl + H in your code editor and replace "VANTA" with your brand name.
Select "Replace All" so the brand name is updated throughout the website.
• Hero headline
• Description
• Services
• Project information
• Pricing
• Contact email
To change the contact email:
Search for "hello@example.com" in index.html and replace it with your own email address.
• Statistics
To change the statistics:
Search for "12+" , "98%" , and "120+" in index.html.
Replace these sample numbers with your own real statistics.
• Colors and fonts
